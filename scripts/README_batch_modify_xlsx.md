# 批量修改XLSX文件指定列数据工具

## 功能介绍

这是一个用Python编写的批量修改Excel文件中指定列数据的工具，主要功能包括：

1. **批量处理**：支持单个XLSX文件或包含多个XLSX文件的目录
2. **列数据修改**：精准定位并修改指定列的数据
3. **智能保留**：只保留指定前缀和文件路径名，删除其他字符串
4. **安全机制**：
   - 模拟修改功能（dry run）
   - 详细的修改日志
5. **灵活配置**：支持命令行参数配置
6. **错误处理**：完善的异常处理机制

## 安装依赖

使用前需要安装以下Python库：

```bash
pip3 install pandas openpyxl
```

## 使用方法

### 基本语法

```bash
python3 batch_modify_xlsx.py <输入路径> <列名> <前缀> [选项]
```

### 参数说明

- `<输入路径>`：XLSX文件路径或包含XLSX文件的目录
- `<列名>`：要修改的Excel列名
- `<前缀>`：要保留的字符串前缀
- `--dry-run` 或 `-d`：模拟修改，不实际保存文件
- `--quiet` 或 `-q`：安静模式，不显示详细修改信息

### 使用示例

#### 1. 查看帮助信息
```bash
python3 batch_modify_xlsx.py --help
```

#### 2. 模拟修改单个文件
```bash
python3 batch_modify_xlsx.py data.xlsx "文件路径" "IMAGE:" -d
```

#### 3. 实际修改单个文件
```bash
python3 batch_modify_xlsx.py data.xlsx "文件路径" "IMAGE:" 
```

#### 4. 批量修改目录下所有XLSX文件
```bash
python3 batch_modify_xlsx.py ./excel_files "图片路径" "IMG:" 
```

#### 5. 安静模式批量修改
```bash
python3 batch_modify_xlsx.py ./excel_files "附件地址" "ATTACH:" -q
```

## 工作原理

1. **读取文件**：使用pandas库读取XLSX文件
2. **定位列**：检查并定位指定的列
3. **处理数据**：
   - 查找单元格中指定的前缀
   - 使用正则表达式提取文件路径部分
   - 只保留前缀和文件路径，删除其他内容
4. **保存结果**：将修改后的数据保存回文件（如果不是模拟模式）

## 正则表达式说明

脚本使用以下正则表达式提取文件路径：

```
[a-zA-Z0-9_/\\:\.\-\s]+\.[a-zA-Z0-9]+
```

该表达式匹配：
- 字母、数字、下划线、斜杠、反斜杠、冒号、点、连字符和空格
- 以点号+扩展名结尾的字符串

## 注意事项

1. **备份数据**：在实际修改前，建议先备份原始Excel文件
2. **前缀匹配**：确保指定的前缀在目标列中存在
3. **列名准确性**：列名必须与Excel文件中的列名完全一致
4. **文件格式**：只支持XLSX格式的Excel文件
5. **路径格式**：脚本会自动识别常见的文件路径格式

## 运行环境

- Python 3.6+
- pandas 1.0+
- openpyxl 3.0+

## 常见问题

### Q: 脚本无法找到指定的列
A: 请检查列名是否与Excel文件中的列名完全一致，包括大小写和空格

### Q: 部分文件路径没有被正确提取
A: 脚本使用正则表达式提取路径，如果路径格式特殊，可能需要调整正则表达式

### Q: 修改后文件无法打开
A: 请确保安装了最新版本的openpyxl库，或者尝试使用其他Excel打开方式

### Q: 如何处理大量文件
A: 可以直接指定包含所有XLSX文件的目录，脚本会自动递归处理所有文件
